Cálculo paso a paso

  1. Contador como 8 bytes big-endian
  2. HS = HMAC-SHA1(K, C) → 20 bytes
    El último nibble (resaltado) define el offset; los 4 bytes en esa posición se extraen.
  3. Truncamiento dinámico
    offset = HS[19] AND 0x0F  ·  P = HS[offset..offset+3] AND 0x7FFFFFFF
  4. Reducción modular
    código = P mod 106
